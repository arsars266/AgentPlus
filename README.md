# AgentPlus
  # 1. Назначение и область применения
  # 1.1 Назначение системы
Информационная система «Агент-Плюс» (далее – Система) предназначена для автоматизации деятельности агентства недвижимости. Система обеспечивает централизованное хранение и обработку информации об объектах недвижимости, клиентах (физических и юридических лицах), заявках на подбор, показах, сделках и документах.

  # 1.2 Цели создания системы
Устранение дублирования и потери данных;

Предотвращение конфликтов при работе с одним объектом нескольких риелторов;

Автоматизация расчёта комиссионных и формирования отчётности;

Ускорение процесса подбора объектов для клиентов;

Обеспечение централизованного учёта и контроля всех этапов работы с недвижимостью.

  # 1.3 Область применения
Система предназначена для использования в агентствах недвижимости, отделах аренды и продаж недвижимости, а также может быть адаптирована для индивидуальных риелторов. Система рассчитана на штат сотрудников от 1 до 50 человек.

  # 3. Архитектура системы
  # 3.1 Общая архитектура
Система построена по трёхуровневой архитектуре «клиент-сервер»:

Уровень представления (Client Tier) – Windows Forms-приложение, обеспечивающее взаимодействие с пользователем.

Уровень бизнес-логики (Business Logic Tier) – реализован в коде C# (классы DatabaseHelper, AuthManager, DataValidation), а также частично на уровне хранимых процедур MS SQL Server.

Уровень данных (Data Tier) – реляционная база данных MS SQL Server.

  # 4. Описание базы данных

  # 5. Руководство администратора
  # 5.1 Установка и развёртывание
Шаг 1. Установка MS SQL Server

Загрузите установщик MS SQL Server Express с официального сайта Microsoft.

Выполните установку, выбрав «Базовая установка».

В процессе установки запомните имя экземпляра (по умолчанию SQLEXPRESS).

Шаг 2. Создание базы данных

Откройте SQL Server Management Studio (SSMS).

Подключитесь к серверу (например, localhost\SQLEXPRESS).

Откройте файл CreateDatabase.sql из папки Database/ репозитория.

Выполните весь скрипт (клавиша F5).

Шаг 3. Настройка строки подключения

Откройте проект в Visual Studio.

В файле DatabaseHelper.cs найдите константу connectionString.

Измените параметры Data Source и Initial Catalog в соответствии с вашим сервером:

csharp
private static string connectionString = "Data Source=localhost\\SQLEXPRESS;Initial Catalog=AgentPlusDB;Integrated Security=True;";
Шаг 4. Компиляция и запуск

Откройте файл решения AgentPlus.sln в Visual Studio.

Нажмите F5 для компиляции и запуска.

Либо скопируйте файлы из папки Releases/AgentPlus_v1.0.zip на рабочий компьютер.

  # 6. Руководство пользователя
  # 6.1 Начало работы
Запустите приложение AgentPlus.exe.

На форме выбора роли нажмите соответствующую кнопку:

«Вход для клиента» – для просмотра объектов и подачи заявок;

«Вход для сотрудника» – для работы риелтора;

«Вход для администратора» – для управления системой.

  # 6.2 Работа клиента
Регистрация:

На форме регистрации введите фамилию, имя, отчество и адрес электронной почты.

Нажмите «Зарегистрироваться».

Просмотр объектов:

После регистрации открывается лента недвижимости.

Используйте поле «Фильтр» для отбора по району или типу операции.

Используйте поле «Поиск» для поиска по адресу.

Подача заявки:

Выберите интересующий объект из списка.

Нажмите кнопку «Подать заявку».

Заполните контактные данные (ФИО, телефон, почта).

Нажмите «Подать заявку». Заявка будет передана администратору для распределения риелтору.

  # 6.3 Работа риелтора
Вход в систему:

На форме выбора роли нажмите «Вход для сотрудника».

Введите логин (адрес электронной почты) и пароль.

Нажмите «Войти».

Рабочая страница:

«Моя статистика» – просмотр личных показателей (количество показов, сделок, комиссионных).

«Списки объектов» – просмотр объектов, закреплённых за риелтором.

«Списки клиентов» – просмотр клиентской базы.

«Посмотреть заявку» – переход к карточке заявки для организации показа.

Организация показа:

Нажмите «Посмотреть заявку».

Заполните информацию о клиенте (ФИО, телефон).

Нажмите «Отправить на подтверждение».

  # 6.4 Работа администратора
Вход в систему:

На форме выбора роли нажмите «Вход для администратора».

Введите фамилию, имя, отчество и адрес электронной почты.

Нажмите «Войти».

Управление данными:

Выберите нужный раздел в MenuStrip: «Объекты недвижимости», «Клиенты», «Заявки», «Сделки», «Документы».

Данные выбранной таблицы отобразятся в DataGridView.

Используйте кнопки панели:

«Обновить» – перезагрузка данных;

«Добавить» – открытие формы для добавления записи;

«Редактировать» – изменение выбранной записи;

«Удалить» – удаление выбранной записи (с подтверждением);

«Поиск» – фильтрация данных.

Регистрация входящих заявок:

Нажмите «Регистрация входящих заявок» в админ-панели.

Заполните информацию о новом клиенте и его пожеланиях.

Нажмите «Сохранить».

Распределение по риелторам:

Нажмите «Распределение по риелторам».

Выберите заявку или объект из списка.

Нажмите «Назначить» и выберите риелтора из выпадающего списка.

  # 7. Тестирование
 # 7.1 Перечень проверяемых сценариев
№	Сценарий	Ожидаемый результат
1	Вход администратора с корректными данными	Открытие админ-панели
2	Вход администратора с некорректными данными	Сообщение об ошибке
3	Регистрация нового клиента	Создание записи в таблице Clients
4	Подача заявки клиентом	Создание записи в таблице ClientRequests
5	Создание сделки через процедуру usp_CreateTransaction	Создание записи в Transactions, обновление статуса объекта на «Sold»
6	Обновление цены объекта	Добавление записи в PriceHistory (триггер)
7	Попытка создания двух показов одного объекта в одно время	Ошибка из-за уникального ограничения
8	Попытка создать сделку для неактивного объекта	Ошибка «Объект не активен»
9	Поиск объектов по району и цене	Корректная фильтрация с использованием индекса
10	Формирование отчёта через представление vw_ActiveTransactionsCommission	Вывод активных сделок с расчётом комиссии
  # 7.2 Результаты тестирования
Все перечисленные сценарии успешно пройдены. Система работает корректно при штатных и нетиповых нагрузках. Время отклика интерфейса при работе с таблицами до 10 000 записей не превышает 2 секунд.

  # 8. Возможные ошибки и способы их устранения
Ошибка	Возможная причина	Способ устранения
Не удаётся подключиться к базе данных	Неверная строка подключения	Проверьте параметры Data Source в connectionString
Ошибка при создании сделки	Объект уже продан или не активен	Проверьте статус объекта в таблице Properties

Медленная загрузка DataGridView	Отсутствие индексов	Выполните скрипт создания индексов из файла Indexes.sql
  # 9. Условия эксплуатации
Режим работы: круглосуточно, с возможностью прерывания для проведения резервного копирования;

Количество одновременно работающих пользователей: до 20;

Частота обновления данных: в реальном времени;

Периодичность резервного копирования: ежедневно (рекомендуется).

  # 10. Заключение
Разработанная информационная система «Агент-Плюс» полностью соответствует требованиям технического задания. Система обеспечивает централизованное управление всей деятельностью агентства недвижимости – от учёта объектов до фиксации завершённых сделок. Реализована ролевая модель доступа с разграничением прав для администратора, риелтора и клиента. База данных спроектирована в третьей нормальной форме, содержит индексы для ускорения поиска, представление для аналитики, хранимую процедуру для безопасного создания сделок и триггер для автоматического логирования изменений цен. Клиентское приложение разработано на C# с использованием Windows Forms, ADO.NET и Entity Framework, обеспечивая высокую производительность и удобство работы.
